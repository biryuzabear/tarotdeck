# OLED module `GM009605v4.3`

**Dropped from the build.** It fits between the gears, but 27 × 27 mm of module
buys only a running line of text — not worth the space or the look.

Generic 0.96" monochrome OLED. The marking is a PCB revision code, not a
controller part number — no datasheet for "GM009605" exists.

| | |
|---|---|
| Size | 0.96 inch, module 27 × 27 × 4.1 mm |
| Resolution | 128 × 64 |
| Interface | I²C (the V4 boards are the 4-pin I²C variant) |
| I²C address | **0x3C** (0x3D if SA0 is pulled high) |
| Voltage | 3.3–5 V |
| Pins | GND, VDD, **SCK**, SDA — the silkscreen "SCK" is I²C **SCL** |

## Controller — not definitively confirmed
Works in practice with `Adafruit_SSD1306` at 128×64 / 0x3C. One retail listing
carrying this exact marking contradicts itself (title says SH1106, spec field
says SSD1306).

Practical test: init as SSD1306. If the image is offset ~2 px horizontally and
wraps, it's an SH1106. SSD1315 needs no change for basic SSD1306 init.

## Known gotcha
Draws ~0.1 W and simply fails to enumerate when under-powered — I²C scans report
"no device" until it gets a proper 3.3 V supply.
